# AstroCrop

Симулятор фермера, который управляет природой: выберите стартовый мир (Землю, Марс, Луну, экзопланету или «пустой мир»), посадите культуру, меняйте условия ползунками и насылайте события — жару, заморозок, засуху, ливень, град, бурю, вспышку звезды. Растение честно реагирует, а отчёт за сезон называет главную причину потерь.

## Запуск

Нужны `uv`, Node.js и `make`.

```bash
make install
make ingest        # скачать каталоги NASA и PHL (без сети сработают кэш и снимок)
make dev-backend   # API на http://localhost:8000, документация на /docs
make dev-frontend  # интерфейс на http://localhost:5173
```

Приложение открывается в **3D-режиме** (`/universe`): Вселенная → галактика → звёздная система → планета → огород. Кликайте по объектам, чтобы лететь к ним; хлебные крошки возвращают на любой уровень; Ctrl+K — поиск планеты. В огороде выберите грядку, культуру и тип укрытия и нажмите ▶. В огороде:

- слева «Природа» — условия по группам, зелёная полоса показывает оптимум культуры, «↺ вернуть как в мире» сбрасывает ползунок;
- внизу таймлайн сезона — ▶ (пробел), скорость, прогноз на 7 дней, графики; «События» открывает колоду: клик по карточке — событие сейчас, перетаскивание на дорожку — запланировать (полосу можно сдвинуть, растянуть, убрать);
- справа «Растение» — здоровье, стрессы с причинами и действия фермера;
- режимы Песочница / Сценарий / Эксперимент / Испытания; в конце сезона — отчёт, «Повторить с изменениями» и «Сохранить сценарий» (ссылка `?scenario=…`).

Таблицы (каталог, прежний симулятор, сравнение) доступны по кнопке «Таблицы». Скриншоты — в [docs/screenshots](docs/screenshots/), дизайн — в [docs/screenshots/design](docs/screenshots/design/), симулятор — в [docs/screenshots/simulator](docs/screenshots/simulator/). Все компоненты дизайн-системы в обоих настроениях — на странице `/dev/ui` (гид — [docs/DESIGN.md](docs/DESIGN.md)).

Через Docker: `make up`, интерфейс откроется на http://localhost:8080.

## Команды

| Команда | Что делает |
|---|---|
| `make test` | тесты бэкенда и фронтенда |
| `make lint` | ruff, mypy, проверка типов фронтенда |
| `make openapi` | заново сгенерировать типы клиента API |
| `make snapshot` | обновить офлайн-снимок реальных планет в `data/seed` |

## Как читать результат

- **Урожайность** в таблицах указана в процентах от земной в хороших условиях и не превышает 100 %. В отчёте огорода есть и «% от нормы» — от того же сезона без событий и действий фермера; полив сверх нормы может дать больше 100 %.
- **Уверенность** снижается за каждое допущение. Список допущений показан рядом с результатом.
- **Оценки.** Физиологические параметры культур пока заданы экспертной оценкой (`estimate=true`), поэтому результаты годятся для сравнения вариантов, а не для точного прогноза.
