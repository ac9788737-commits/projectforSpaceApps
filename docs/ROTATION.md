# WhatCropNext — Этап 7: планировщик севооборота на реальных данных NASA

> Положи файл в `docs/ROTATION.md`. Он **меняет позиционирование проекта** и закрывает пять разрывов из gap-анализа. Правила из `CLAUDE.md` (данные без выдумок, тесты, коммиты, автономный режим) и `docs/DESIGN.md` действуют. Первым делом обнови раздел «Цель проекта» в `CLAUDE.md` по §0.

## 0. Новая цель продукта

**Фермер выбирает реальное поле на карте Земли. Система подтягивает спутниковые и климатические данные NASA за 10–20 лет, находит уязвимые периоды (голая почва, жара, засуха, заморозки) и сравнивает несколько схем севооборота на 3–5 лет по приоритетам фермера — с оценкой неопределённости и честным списком пробелов в данных.**

- Главное решение фермера — **схема севооборота на открытом грунте**, а не управление погодой.
- Ползунки погоды из этапа 6 превращаются в **«Стресс-тест климатических сценариев на 5–10 лет»** (например, +1.5 °C и −15 % осадков). Это изменения поверх реальной истории, а не «режим бога».
- Космос (планеты, купола, экзопланеты) уходит в отдельный необязательный режим **«Лаборатория»** за фича-флагом `FEATURE_SPACE_LAB`. В основном сценарии его не видно.
- Существующий почасовой движок (этап 6) остаётся ядром расчёта одного сезона; поверх него строится многолетний слой.

## 1. Разрыв 1 → Многолетний севооборот с переходящим состоянием почвы

### 1.1 Модель данных
```
Field        — поле: полигон, площадь, привязанные слои данных
Rotation     — схема: последовательность слотов на N лет
Slot         — {год, сезон: main | cover | fallow, культура | "голое поле", даты сева/уборки, действия}
SoilState    — состояние почвы, которое ПЕРЕХОДИТ из слота в слот
```

`SoilState` (всё — в слое `0–30 см`, а для воды — по зоне корней):

| Поле | Что значит | Кто меняет |
|---|---|---|
| `soc_pct` | органический углерод | пожнивные остатки, покровные культуры, эрозия, минерализация |
| `n_mineral_kg_ha` | доступный азот | удобрения, фиксация бобовыми, минерализация остатков, вынос урожаем, вымывание |
| `residue_kg_ha`, `residue_cn` | остатки предшественника | уборка → медленное разложение |
| `infiltration_idx` | структура / впитывание | глубокие корни (+), уплотнение техникой (−), голая почва (−) |
| `water_mm` | запас влаги на начало слота | водный баланс |
| `cover_frac` по дням | доля покрытия почвы | культура / покровная / голое поле |
| `pest_pressure[family]` | давление вредителей и болезней по семействам | растёт при повторе семейства, падает при разрыве |
| `erosion_loss_t_ha` | накопленная потеря почвы | RUSLE (см. §1.3) |

### 1.2 Свойства культур
Добавить в `data/seed/crops.csv` (с колонкой `reference` для каждого числа, без источника — `estimate=true`):
`family` (бобовые, злаковые, паслёновые, капустные, тыквенные…), `n_fixation_kg_ha` (бобовые), `root_depth_m`, `residue_cn`, `harvest_index`, `is_cover_crop`, `min_break_years` (сколько лет нельзя повторять семейство), `feed_value` (протеин / энергия на тонну, для кормовых).
Минимальный набор культур: пшеница, ячмень, кукуруза, горох, нут, люцерна, соя, картофель, томат, хлопок, подсолнечник, + покровные: вика, клевер, рожь на зелёное удобрение, горчица, фацелия.

### 1.3 Модели (простые, прозрачные, из признанных методик)
- **Водопотребление:** эталонное испарение по FAO-56 (Penman–Monteith) × коэффициент культуры Kc по стадиям.
- **Урожай при нехватке воды:** подход FAO AquaCrop. Рассмотри подключение открытой Python-реализации **AquaCrop-OSPy** (`pip install aquacrop`) как основного или проверочного движка для открытого грунта Земли. Если её используешь — сверяй с ней свой движок в тестах.
- **Азот:** упрощённый баланс (вход: удобрения + фиксация + минерализация остатков с учётом C:N; выход: вынос урожаем + вымывание при избытке воды). Бобовый предшественник → бонус азота следующей культуре.
- **Эрозия:** RUSLE `A = R·K·LS·C·P`. R — из осадков, K — из почвы SoilGrids, LS — из уклона SRTM, C — из покрытия почвы по дням (культура / покровная / голое поле), P — из практики (по горизонталям, террасы).
- **Вредители/болезни:** индекс давления по семействам: растёт при повторе, затухает за `min_break_years`; снижает урожай по таблице. Явно помечать в UI как **упрощённую эвристику**.
- **Структура почвы:** глубокие корни (`root_depth_m ≥ 1.2`) и покровные культуры повышают `infiltration_idx`, что увеличивает впитывание и снижает сток в следующих слотах.

### 1.4 Агрономические правила (валидатор схемы)
`rotation/rules.py`: не повторять семейство раньше `min_break_years`, не ставить бобовые после бобовых, голое поле в сезон эрозионных ливней → предупреждение, покровная культура должна успеть вырасти между уборкой и севом. Нарушения показывать в UI, а не запрещать молча.

## 2. Разрыв 2 → Реальное поле и слои NASA

### 2.1 Выбор поля
- Карта: **MapLibre GL** + базовая подложка OpenStreetMap (с атрибуцией) + слои **NASA GIBS** (WMTS) для визуального контекста (MODIS/VIIRS снимки, NDVI).
- Поиск по адресу/координатам, рисование полигона поля, загрузка GeoJSON/KML.
- Первая вкладка демо-полей (например, в Таджикистане, США, Индии, Кении) с заранее закешированными данными, чтобы демо работало без сети.

### 2.2 Источники
| Слой | Что даёт | Разрешение | Доступ |
|---|---|---|---|
| **NASA POWER** | суточные T min/max, осадки, радиация, влажность, ветер — с 1981 г. | ~0.5° | открытый REST API без ключа |
| **GPM IMERG** | осадки | ~0.1°, до 30 мин | NASA Earthdata (логин) |
| **SMAP L3/L4** | влажность почвы | 9–36 км | Earthdata |
| **ECOSTRESS** | температура поверхности, эвапотранспирация, тепловой стресс | ~70 м, с 2018 г., нерегулярно | Earthdata / AppEEARS |
| **MODIS (MOD13Q1) / HLS (Landsat+Sentinel-2)** | NDVI → когда поле было голым | 250 м / 30 м | AppEEARS / Earthdata |
| **SRTM** | рельеф → уклон, LS-фактор | 30 м | Earthdata / AppEEARS |
| **GRACE / GRACE-FO** | долгосрочный тренд запасов воды | очень грубое (сотни км), месячное | Earthdata (только как региональный контекст!) |
| **SoilGrids (ISRIC)** | текстура, органика, pH, плотность | 250 м | REST API / WCS |

Инструменты: `earthaccess` (авторизация и поиск в Earthdata), **AppEEARS API** (вырезка по полигону/точке для MODIS, ECOSTRESS, SMAP, SRTM и др. — одна точка входа), `xarray`, `rioxarray`, `rasterio`, `geopandas`. Токен Earthdata — только через `.env`, никогда в коде и в коммитах.

### 2.3 Согласование разрешений (harmonization)
Модуль `backend/app/geo/harmonize.py`:
- **Единица анализа — поле (полигон).** Для каждого слоя: если пиксель меньше поля — среднее по полигону с весом площади; если больше — значение пикселя, накрывающего поле, + флаг `coarse=true` и отношение размера пикселя к полю.
- **Время — сутки.** NDVI (16 дней) — интерполяция с флагом; облачные пропуски — маска качества → пропуск, а не ноль; SMAP — суточный с пропусками; GRACE — месячный, используется только как тренд.
- **Для каждого значения храним:** источник, исходное разрешение (пространственное и временное), доля пропусков, флаг качества, дату загрузки. Это идёт прямо в блок «Пробелы в данных» (§5.2).
- Хранение: Parquet (ряды) + Zarr/GeoTIFF (растры) в `data/cache/<field_id>/`, загрузка идемпотентна.
- Отчёт согласования `GET /fields/{id}/data-card`: таблица слоёв, покрытие по годам, разрешение, проблемы.

## 3. Разрыв 3 → Анализ истории и подбор стратегий

### 3.1 Анализ 10–20 лет по полю (`analysis/history.py`)
- **Периоды без покрова:** NDVI ниже порога голой почвы (порог калибровать по региону, по умолчанию ~0.2–0.25) ≥ N дней подряд. Наложить на календарь ливней → «окна эрозионного риска».
- **Аномальная жара:** дни с Tmax выше 90-го перцентиля для этого календарного окна (по многолетнему ряду), ≥ 3 дней подряд; + ECOSTRESS там, где есть.
- **Засуха:** индексы SPI / SPEI (осадки и осадки − эталонное испарение) на шкалах 1–3 месяца; + аномалии SMAP.
- **Заморозки:** распределение дат последнего весеннего и первого осеннего заморозка → вероятности по датам.
- **Окна уязвимости:** наложение чувствительных стадий культур (цветение, налив, клубнеобразование) на историческую вероятность опасных явлений → «В 7 из 20 лет на цветение пшеницы приходилась жара > 35 °C».

### 3.2 Подбор и ранжирование севооборотов (`rotation/optimizer.py`)
1. **Генерация кандидатов:** перебор схем на 3–5 лет из культур, доступных фермеру (§4), с отсечением по агроправилам (§1.4). Если вариантов слишком много — эволюционный поиск (например, NSGA-II из `pymoo`).
2. **Ансамбль погоды:** каждая схема прогоняется по каждому историческому году как по возможной погоде (+ сдвиг начала, чтобы перемешать порядок лет) → распределение результатов, а не одно число.
3. **Климатический стресс-тест:** те же прогоны с изменениями поверх истории (дельта-метод: +ΔT ко всем температурам, ×(1+ΔP) к осадкам, усиление волн жары). Пресеты: «Как в истории», «+1 °C», «+1.5 °C и −15 % осадков», «Сухие вёсны», «Больше дней > 35 °C». Горизонт — 5–10 лет.
4. **Метрики по схеме:** урожай (P10/P50/P90), доход, вода, азот и органика в конце, эрозия, вероятность провала (урожай < X % нормы), дни голой почвы.
5. **Ранжирование:** по весам приоритетов фермера (§4) + **фронт Парето** (схемы, которые нельзя улучшить по одной цели, не ухудшив другую). Показывать оба вида.
6. **Неопределённость:** интервалы P10–P90 из ансамбля + пометка, какие входы самые неуверенные (анализ чувствительности: что сильнее всего меняет результат).
7. **Суррогатная модель (по желанию):** если прогонов слишком много — обучить градиентный бустинг (`lightgbm`) на результатах движка для быстрого отсева, затем точный пересчёт топ-20 движком. Всегда показывать, что итоговые цифры — из движка, а не из суррогата.

### 3.3 Объяснения на естественном языке
Опционально — через Claude API: модель получает **только посчитанные числа и таблицы** и пишет короткое объяснение для фермера («Схема B даёт на 8 % меньше пшеницы, но экономит 1 200 м³ воды на гектар и вдвое снижает эрозию за счёт вики зимой»). Правило: в объяснении нет ни одной цифры, которой нет во входных данных; это проверяется тестом. Ключ API — в `.env`. Без ключа — шаблонные объяснения.

## 4. Разрыв 4 → Приоритеты, ограничения и экономика фермера

### 4.1 Анкета фермера (мастер на 3 шага)
- **Приоритеты** (ползунки весов 0–5): урожай, доход, экономия воды, кормовая ценность, рост органики и азота, снижение эрозии, низкий риск провала, меньше труда.
- **Ограничения:** доступная техника (сеялка для мелкосемянных, комбайн, картофелекопалка…), есть ли орошение и лимит воды (м³/га/год), культуры обязательные / запрещённые, рыночный спрос (какие культуры можно продать), бюджет на семена и удобрения, горизонт планирования (3–5 лет).
- Профили-пресеты: «Водосбережение», «Корма для скота», «Восстановление почвы», «Максимум дохода».

### 4.2 Экономика
- Таблица цен и затрат (`data/seed/economics_<регион>.csv`): цена культуры, семена, удобрения, работа техники, вода. **Значения по умолчанию — с источником и датой; фермер может их отредактировать**, и редактирование сразу пересчитывает рейтинг.
- Метрики: валовой доход и маржа на гектар по годам и за весь севооборот, + их разброс по ансамблю погоды.
- Кормовая ценность: протеин и обменная энергия с гектара (для кормовых культур).

### 4.3 Сравнение стратегий
- Главный экран сравнения: 3–5 лучших схем столбцами; строки — метрики приоритетов фермера с интервалами; полоса «Риск провала».
- Радар по приоритетам, график Парето (две выбираемые оси, например «доход» и «вода»).
- Временная лента каждой схемы: год → сезон → культура, цветом семейства; под ней — линия органики, азота и покрытия почвы по годам.
- Кнопка «Почему это место?» → объяснение (§3.3) и вклад каждой метрики в итоговый балл.

## 5. Разрыв 5 → Позиционирование и честность

### 5.1 Переделка интерфейса
- Новый главный путь: **Карта → Поле → Анализ истории → Приоритеты → Сравнение севооборотов → План**.
- Панель погоды из этапа 6 переименовать в **«Стресс-тест климата»**: ползунки ΔT, Δосадков, частота жары/засух, горизонт 5–10 лет; подпись «Это не прогноз, а проверка устойчивости схемы к возможным изменениям климата».
- Отдельные погодные события (буря, град) остаются **только как сценарии стресс-теста**, а не как «насылание».
- 3D-огород остаётся как **визуализация** выбранной схемы: поле по годам и сезонам, покровная культура зимой, голая почва, всё по реальным датам.
- Всё «космическое» — во вкладке «Лаборатория» за фича-флагом.

### 5.2 Блок «Пробелы в данных и риски: что проверить агроному на месте»
Обязательный блок на экранах «Поле», «Сравнение» и в итоговом отчёте. Генерируется автоматически:
- **Данные:** какие слои отсутствуют или имеют пропуски (например, «ECOSTRESS: 14 снимков за 6 лет»), где разрешение грубее поля («SMAP 9 км против поля 4 га — влажность почвы усреднена по большой площади»), где использованы оценки вместо измерений (`estimate=true`).
- **Модель:** что упрощено (вредители — эвристика, азот — упрощённый баланс, местные сорта не учтены).
- **Чек-лист агронома:** анализ почвы (pH, азот, фосфор, калий, органика), засолённость, дренаж и уровень грунтовых вод, история вредителей и болезней на поле, местные сорта и сроки сева, качество и доступность поливной воды, уклоны и промоины на месте.
- Постоянная пометка: «Это инструмент поддержки решений, а не замена агроному».

## 8. Тесты и критерии готовности

- Горох/нут перед пшеницей → у пшеницы больше доступного азота и (при прочих равных) урожай выше, чем после пшеницы.
- Покровная культура в межсезонье → меньше дней голой почвы, меньше эрозии по RUSLE, больше органики к концу севооборота, чем с паром.
- Картофель после томата (оба паслёновые) → выше давление вредителей, чем картофель после пшеницы; валидатор правил выдаёт предупреждение.
- Культура с глубокими корнями повышает `infiltration_idx`, и следующая культура теряет меньше воды со стоком.
- Стресс-тест «+1.5 °C и −15 % осадков» не улучшает водный баланс ни одной схемы без орошения.
- Согласование разрешений: синтетический растр с известными значениями → правильное взвешенное среднее по полигону; флаг `coarse` выставляется корректно.
- Для демо-поля без сети всё работает из кеша.
- В объяснениях (§3.3) нет цифр, которых нет во входных данных.
- Один и тот же вход + seed → одинаковый рейтинг.

**Сквозной путь для демо:**
> Открыть карту → выбрать демо-поле → увидеть историю за 20 лет: «в среднем 140 дней голой почвы в год, в 6 из 20 лет — жара на цветении пшеницы» → выставить приоритеты «экономия воды + рост органики», техника без картофелекопалки → получить 3 схемы с интервалами урожая, воды, эрозии и дохода → включить стресс-тест «+1.5 °C, −15 % осадков» и увидеть, как поменялся рейтинг → прочитать «Пробелы в данных и риски» → скачать план.

После каждого подэтапа: тесты, линтер, скриншоты по чек-листу `DESIGN.md` §12, коммит, запись в `docs/PROGRESS.md`.
