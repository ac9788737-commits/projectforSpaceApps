# WhatCropNext — Этап 5: интерактивный 3D-режим

> Положи этот файл в `docs/INTERACTIVE.md`. Это продолжение `CLAUDE.md`: все правила оттуда (данные без выдумок, тесты, коммиты, автономный режим) действуют и здесь.

## 1. Идея

Пользователь не заполняет формы, а **путешествует**:

```
Вселенная → Галактика → Звёздная система → Планета (орбита) → Поверхность (огород) → Растение крупным планом
```

Пример сценария: открываю приложение → вижу Млечный Путь → нахожу точку «Солнце» → приближаюсь, вижу Солнечную систему с планетами на орбитах → кликаю Марс → камера подлетает к планете, потом «садится» на поверхность → вижу огород на красном грунте под рыжим небом → выбираю «Картофель» и тип грядки (открытый грунт / купол / подземная ферма) → нажимаю ▶ → картофель растёт по дням, видно, как он реагирует на холод, слабый свет и низкую гравитацию, и под землёй в разрезе растут клубни → в конце показан итог урожая.

**Главный принцип: визуализация — это отображение реальных данных симуляции, а не просто анимация.** Высота куста, цвет листьев, число клубней, увядание — всё берётся из таймлайна, который возвращает бэкенд.

## 2. Стек фронтенда (дополнение)

| Что | Технология |
|---|---|
| 3D | `three`, `@react-three/fiber`, `@react-three/drei` |
| Эффекты | `@react-three/postprocessing` (bloom для звёзд, лёгкая виньетка) |
| Анимация переходов камеры | `@react-spring/three` или `camera-controls` (через drei `CameraControls`) |
| UI поверх сцены | React + Tailwind + `framer-motion` |
| Глобальное состояние | `zustand` (текущий уровень, выбранные объекты, время симуляции, скорость) |
| Роутинг | `react-router` — каждый уровень имеет URL: `/galaxy/milky-way/system/sol/planet/mars/garden` |
| Производительность | `InstancedMesh` для звёзд и растений, LOD, `Suspense` + ленивая загрузка уровней |

Ассеты: **только процедурная генерация или свободно лицензированные текстуры** (например, карты планет NASA — public domain; текстуры с лицензией CC BY — с указанием автора в `docs/CREDITS.md`). Никаких моделей и текстур с неясной лицензией.

## 3. Уровни сцены

### 3.1 Вселенная (`/universe`)
- Несколько галактик как светящиеся облака частиц: Млечный Путь, Большое и Малое Магеллановы Облака, Андромеда + пресеты гипотетических галактик из `galaxies.py`.
- У каждой галактики есть плашка: тип, число известных планет («0 подтверждённых — только гипотетические миры»).
- Клик → перелёт камеры в галактику.

### 3.2 Галактика (`/galaxy/:id`)
- Процедурная спиральная галактика (частицы, рукава по логарифмической спирали, ядро с bloom).
- Для Млечного Пути: отмечено положение Солнца. Все известные экзопланетные системы находятся очень близко к Солнцу (в масштабах галактики), поэтому:
  - при приближении к Солнцу показывается «пузырь» соседних звёзд;
  - звёзды с планетами — по реальным координатам (RA/Dec + расстояние из NASA Exoplanet Archive → декартовы координаты), цвет по `st_teff`.
- Фильтры поверх сцены: «только с планетами в обитаемой зоне», тип звезды, расстояние.
- Для других галактик: сгенерированные звёздные системы с пометкой «гипотетическая».

### 3.3 Звёздная система (`/system/:id`)
- Звезда в центре: размер и цвет по `st_rad` и `st_teff`, свечение.
- Планеты на орбитах (масштаб сжат, но порядок и относительные размеры сохранены; переключатель «реальный масштаб» для любопытных).
- Подсветка обитаемой зоны кольцом.
- Наведение на планету → карточка: радиус, масса, гравитация, температура, освещённость, + **быстрый вердикт «Можно ли тут что-то вырастить?»** (лучший сценарий из симуляции).
- Клик → перелёт к планете.

### 3.4 Планета (`/planet/:id`)
- Вращающаяся планета: текстура для известных (Солнечная система), процедурная для экзопланет (тип: каменистая / ледяная / океан / лавовая — по температуре и плотности), атмосфера — шейдер свечения по краю, цвет по пресету атмосферы.
- Кнопка **«Высадиться»** → анимация спуска (облёт → приближение → переход на поверхность с затемнением/облаками).

### 3.5 Поверхность и огород (`/planet/:id/garden`) — главный экран
**Окружение строится из рассчитанной среды планеты:**
- Небо: цвет по атмосфере (Марс — рыжевато-коричневое днём, голубоватый закат; без атмосферы — чёрное со звёздами), размер и цвет звезды на небе — по угловому размеру и `st_teff`.
- Освещение: интенсивность по освещённости, цвет по спектру звезды; длина дня по периоду вращения; при приливном захвате солнце стоит на месте.
- Грунт: цвет и текстура по типу (реголит Марса, лёд, базальт), процедурный рельеф.
- Погода/частицы: пыль на Марсе, снег/иней при низких температурах.

**Огород:**
- Сетка грядок (например, 3×3). Каждая грядка: культура + сценарий.
- Сценарии визуально разные:
  - **A. Открытый грунт** — грядка прямо на поверхности;
  - **B. Купол** — прозрачный купол над грядкой (шейдер стекла), внутри более тёплый свет;
  - **C. Подземная ферма** — камера «спускается» в помещение со стеллажами и розово-фиолетовым LED-светом.
- Панель выбора культуры: карточки с иконками (процедурные), основные требования.
- Можно посадить разные культуры рядом и сравнить в реальном времени.

**Время:**
- Панель: ▶ / ⏸ / скорость (1 день/с, 5, 20), ползунок по дням, счётчик «Сол 47» (на Марсе — солы, на других планетах — местные сутки + земные дни в подсказке).
- События на таймлайне: заморозок, пылевая буря, вспышка звезды, гибель растения — маркеры на ползунке и всплывающие уведомления.

### 3.6 Растение крупным планом
- Клик по растению → камера приближается, сбоку панель:
  - графики по дням: биомасса, высота, урожай, факторы стресса;
  - текущий лимитирующий фактор крупно («Свет: 43% от оптимума»);
  - для корнеплодов/клубней (картофель, морковь, редис) — **разрез почвы**: видно, как растут клубни.
- Кнопка «Что если…» — меняет один параметр (купол, LED, подогрев) и сразу пересчитывает.

## 4. Процедурные модели растений

Растения генерируются кодом, не загружаются как модели. Модуль `frontend/src/plants/`:

- Общий интерфейс:
  ```ts
  interface PlantState {
    day: number;
    stage: 'seed' | 'germination' | 'vegetative' | 'flowering' | 'fruiting' | 'mature' | 'dead';
    heightM: number;
    leafCount: number;
    leafAreaIndex: number;
    biomassG: number;
    yieldG: number;          // клубни / плоды / листья
    organCount: number;      // число клубней, плодов
    stress: { temp: number; light: number; water: number; gravity: number; radiation: number }; // 0..1
    health: number;          // 0..1
  }
  ```
- Генератор на культуру (`potato.ts`, `lettuce.ts`, `wheat.ts`, `tomato.ts`, …): из `PlantState` строит геометрию (L-система или параметрический генератор: стебли, листья, цветы, плоды/клубни).
- **Визуальное кодирование стресса:**
  - холод → синевато-фиолетовые листья, поникшие;
  - жара/засуха → жёлтые, скрученные края;
  - мало света → вытянутые бледные стебли (этиоляция);
  - низкая гравитация → более высокий, тонкий, «раскидистый» силуэт (экстраполяция, помечать как модель);
  - радиация → пятна/некроз;
  - гибель → коричневое, опавшее.
- Плавная интерполяция между днями (без скачков), лёгкое покачивание от «ветра», если есть атмосфера.
- Через `InstancedMesh` должно спокойно тянуть ≥ 200 растений.

## 5. Изменения в бэкенде

Новый эндпоинт — **таймлайн роста по дням**:

```
POST /simulate/timeline
{ planet_id | custom_planet, crop_id, scenario, atmosphere_preset?, overrides? }
→ {
    environment: {...},              // рассчитанная среда (небо, свет, длина дня, температуры)
    days: PlantState[],              // по одному на местные сутки
    events: [{day, type, message}],  // заморозок, буря, гибель...
    summary: { yield_rel, days_to_harvest, limiting_factor, confidence, assumptions[] }
  }
```

- Посуточная модель: суточный ход температуры и освещённости → факторы отклика (из `biology/responses.py`) → прирост биомассы (через использование света / RUE) → распределение по органам по стадиям развития (сумма эффективных температур / GDD) → урожай.
- Стохастические события (пылевые бури на Марсе, вспышки M-карликов) — с фиксированным `seed`, чтобы результат был воспроизводим.
- Итоговая урожайность таймлайна должна сходиться с уже существующим `/simulate` (тест!).
- Кешировать результаты по хешу входных параметров.

Также добавить:
```
GET /scene/universe          галактики + пресеты
GET /scene/galaxy/:id        звёзды с планетами (координаты, цвет, флаги)
GET /scene/system/:id        звезда + планеты + обитаемая зона
GET /scene/planet/:id        параметры для рендера (тип поверхности, цвет неба, длина дня…)
```

## 6. UX-детали

- Хлебные крошки сверху: `Вселенная › Млечный Путь › Солнечная система › Марс › Огород` — по ним можно вернуться на любой уровень.
- Поиск (Ctrl+K): ввести «TRAPPIST-1e» → перелёт прямо туда.
- Мини-подсказки при первом запуске (3–4 шага).
- Плашки «реальные данные / оценка / гипотетический мир» везде, где показываются цифры.
- Всё в одном окне, переходы плавные (камера летит, а не перезагружается страница).
- Работает на ноутбуке без мощной видеокарты: при низком FPS автоматически снижать качество (меньше частиц, без постобработки).

## 8. Критерии готовности

- Путь «Млечный Путь → Солнце → Марс → Огород → Картофель → ▶» проходится без перезагрузки страницы, кликами мышью.
- Картофель на Марсе в открытом грунте погибает (и видно почему), под куполом растёт медленнее земного, в подземной ферме — близко к земному. Цифры совпадают с `/simulate`.
- На Земле тот же картофель выглядит здоровым и даёт ~100%.
- FPS ≥ 30 на обычном ноутбуке в огороде с 9 грядками.
