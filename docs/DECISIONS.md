
## Дизайн v2 «полевой журнал» (docs/DESIGN.md)
- **Noto Serif вместо Literata.** У Literata нет таджикских ӣ ӯ ҳ ҷ (проверено по таблице символов шрифта), по правилу §3 взята антиква той же роли из Noto. Golos Text содержит все буквы. Подтверждение — `docs/screenshots/design/fonts.png` и список загруженных шрифтов: расширенная кириллица (U+0460–052F) грузится из обоих.
- **Tailwind 4 без `tailwind.config.ts`:** токены и шкала шрифтов заданы в `@theme` (`src/index.css`) и `src/styles/tokens.css` — это то же самое место, что и config в Tailwind 3.
- **Продукт на `data-mood="field"`**, старые имена токенов (`bg-panel`, `text-fg`, `text-ok`…) указывают на новые цвета, поэтому все компоненты сразу стали «бумажными». Лаборатория остаётся на `space` / `garden` и тёмной (§7), но без свечения: Bloom и виньетка убраны из 3D.
- **`design-lint` проверяет продукт, а не Лабораторию:** исключены `explore/`, `plants/`, страницы и набор компонентов, которые импортирует только Лаборатория (`ui/time|data|Logo|CropIcon`, `ui/charts`, `components/ui`). Кроме списка §10.2 линтер ловит SVG-градиенты (`<linearGradient>`) и любые эмодзи.
- **Цвет почвы — непрерывный по шкале Манселла** (`ui/soilColor.ts`): между пятью фишками цвет смешивается, иначе изменение органики на 0,08 % за план было бы не видно. Толщина горизонта в разрезе — «Запас почвы», срезанный край — накопленный смыв (в разрезе в масштабе преувеличен), корни — `root_depth_m` культуры из таблицы (добавлено в ответ колоды).
- **Контур поля на снимке рисует клиент** линией `--ink` 2 px по границам, которые теперь отдаёт API (`bounds`); сервер больше не «вжигает» оранжевый контур в PNG. Версия ключа кеша снимков поднята, снимки демо-полей пересняты (свежий Sentinel-2, 22.10–14.11.2026). `save_demo` теперь запрашивает свежую сцену напрямую, а не находит уже сохранённую.
- **Изолинии рельефа на снимке не нарисованы:** у поля есть только средний уклон, сетки высот нет — рисовать придуманные изолинии нельзя.
- **2.5D-поле осталось только для «Прожить 4 года»** (как разрешает §7 для 3D) — плоские цвета, почва по Манселлу, без градиента неба и «дыхания» жары. Главный элемент экрана 2 — план поля с разрезом; мини-график «Запас почвы» удалён, его ряд по годам — подписью под разрезом.
- **Подпись совета и кеш:** «План под ваши приоритеты: вода и почва» без эмодзи; в ключ кеша советов добавлена версия текста, предрасчёт демо-полей пересчитан.

## Палитра «ферма» (v3)
- **По просьбе пользователя интерфейс перекрашен в фермерские зелёные цвета;** функции не менялись. Цветовая система построена по правилам elayadesign/ai-design-skills (MIT): два слоя — базовые палитры Primary (поле, листва), Secondary (земля), Accent (спелая пшеница, насыщенность < 80 %), Grayscale (соломенные нейтральные; тёмные ступени — ровно разрешённые там тёмные фоны), Red / Green / Yellow с оттенками 00…1000, и токены по ролям (`--cs-surface-*`, `--cs-text-*`, `--cs-border-*`, `--cs-action-*`), которые только ссылаются на палитры. Старые имена (`--paper`, `--ink`, `--rule`…) теперь указывают на роли, поэтому компоненты перекрасились без изменения логики.
- **Готовой зелёной палитры в репозитории нет** — там только правила и тёмные фоны; зелёные палитры подобраны здесь. Контраст проверен: текст 13,8:1, второй текст 6,4:1, белый на зелёной кнопке 6,4:1, текст на пшеничной кнопке 5,9:1, слова статуса ≥ 6:1.
- **Из набора взяты также:** плоские фоны, рамка карточки со всех сторон (полоса цвета семейства у карточки культуры — внутри, а не рамка сверху), радиусы Tailwind (карточки 12 px, кнопки 8 px), кривая движения `cubic-bezier(0.22, 1, 0.36, 1)` и переходы цвета 300 мс.
- **Не взяты:** шрифты набора (Geist, Manrope, Poppins) — оставлены Golos Text и Noto Serif, у которых проверены таджикские ӣ ӯ ҳ ҷ; градиент на заголовке, «плывущая» навигация с размытием и появление секций при прокрутке — противоречат запрету градиентов, стекла и анимаций входа в docs/DESIGN.md; иконки Phosphor — оставлены свои пиктограммы культур. Данные-цвета (Манселл для почвы, семейства культур, синий для воды) не менялись.
- **Вывеска фермы:** общая тёмно-зелёная шапка `ui/AppBar.tsx` на всех экранах продукта; главное действие в ней — кнопка цвета пшеницы (`Button variant="accent"`).

## Дизайн v3 «живое поле»
- **v3 главнее v2,** но шрифт заголовков остался Noto Serif: в Literata, которую называет v3, нет таджикских ӣ ӯ ҳ ҷ (проверено ранее); v3 требует проверку таджикских букв.
- **Полосы поля показывают, что стоит на поле в выбранный месяц,** для каждого года — из недельного ряда модели (того же, что «Прожить 4 года»): летом — основная культура в своей стадии, зимой — покровная или голая почва со стернёй. Ползунок меняет месяц для всех лет сразу; текущий год обведён.
- **Анимации без новых библиотек** (framer-motion не ставился — медленная сеть): CSS-переходы и keyframes в `styles/tokens.css`, пружина — `cubic-bezier(0.34, 1.56, 0.64, 1)`.
- **Перетаскивание по курсору** (`pointerWithin`, запасной вариант — пересечение) и пересчёт целей при прокрутке: колода ниже поля, и при переносе пакета страница прокручивается; без этого полосы «не ловили» пакет.
- **2.5D-поле этапа 8 (`FieldView`) и плоская карточка колоды удалены** — их заменили пейзаж и семенные пакеты.
