# AstroCrop — дизайн-система и визуальный стиль

> Положи файл в `docs/DESIGN.md`. Это обязательный гид по внешнему виду для всех экранов. Если код расходится с этим документом, прав документ.

## 1. Концепция: «Холодный космос → тёплый огород»

Стиль смешанный, и это сделано намеренно:

- **Космос** (вселенная, галактика, звёздная система, планета) выглядит **реалистично и строго**: глубокий чёрно-синий, настоящие цвета звёзд, тонкие линии орбит, минимум декора. Ощущение — обсерватория, атлас NASA.
- **Огород** (поверхность, грядки, растения) **уютный и стилизованный**: low-poly, мягкие формы, тёплый свет, растения немного «игрушечные» и милые. Ощущение — уютная игра-ферма, но на чужой планете.
- **Переход между ними — главный эмоциональный момент.** При посадке на планету холодная палитра интерфейса плавно теплеет, линии становятся мягче, панели — округлее.

Интерфейс один и тот же на всех уровнях (одни компоненты), но **меняет «температуру»** через CSS-переменные: `data-mood="space"` и `data-mood="garden"`.

**Три слова, которыми проверяем каждый экран:** *спокойно, живо, честно* (данные всегда видны и подписаны, без лишнего «кино»).

## 2. Цвета

Все цвета задаются как CSS-переменные в `frontend/src/styles/tokens.css` и дублируются в `tailwind.config.ts`. **Хардкод цветов в компонентах запрещён.**

| `--border-subtle` | `rgba(148, 170, 220, 0.14)` | границы панелей, орбиты |

### 2.3 Семантические цвета (одинаковые везде)
| Токен | Значение | Смысл |
|---|---|---|
| `--ok` | `#5BE3A6` | фактор в норме |
| `--stress` | `#FFC857` | стресс |
| `--lethal` | `#FF6B6B` | смертельно |
| `--data-real` | `#7CC4FF` | бейдж «реальные данные» |
| `--data-estimate` | `#C3A6FF` | бейдж «оценка / модель» |
| `--data-hypo` | `#FF9EC7` | бейдж «гипотетический мир» |

**Цвет никогда не единственный носитель смысла:** статус фактора всегда дублируется иконкой (✓ / ⚠ / ✕) и текстом. Палитру статусов проверить на дальтонизм (дейтеранопия, протанопия).

### 2.4 Цвета небесных тел — из данных, не из палитры
- Цвет звезды — из `st_teff` (функция «температура → RGB» по излучению чёрного тела, `utils/blackbody.ts`). Солнце ≈ тёплый белый, M-карлики — оранжево-красные, горячие звёзды — бело-голубые.
- Цвет неба и освещения в огороде — из пресета атмосферы и спектра звезды (см. §6).

## 3. Типографика

Только свободные шрифты (лицензия OFL), подключаемые локально через `@fontsource`:

| Роль | Шрифт | Где |
|---|---|---|
| Заголовки, названия планет | **Space Grotesk** 500/600 | «Марс», «Солнечная система» |
| Основной текст и UI | **Inter** 400/500 | кнопки, описания, подсказки |
| Цифры и данные | **JetBrains Mono** 400 | `−63 °C`, `0.38 g`, `Сол 47` |

Шкала: `12 / 14 / 16 / 20 / 28 / 40 / 64 px`. Название текущего объекта на экране уровня — 40–64 px, **с большим разрядкой (`letter-spacing: 0.04em`) в космосе** и обычным — в огороде.

Числа всегда: моноширинные, с единицами в `--text-secondary` (`-63` основной цвет, `°C` вторичный), с правильным минусом `−` и неразрывным пробелом.

## 4. Сетка и раскладка экрана

Сцена 3D занимает **весь экран**. Интерфейс плавает поверх неё в четырёх зонах и никогда не закрывает центр:

```
┌───────────────────────────────────────────────────────┐
│ [логотип] Вселенная › Млечный Путь › Солнце › Марс  🔍 │  ← верхняя полоса: хлебные крошки, поиск
│                                                       │
│ ┌──────────┐                           ┌────────────┐ │
│ │ Левая    │                           │ Правая     │ │
│ │ панель:  │        3D-СЦЕНА           │ панель:    │ │
│ │ фильтры/ │     (центр свободен)      │ инфо об    │ │
│ │ выбор    │                           │ объекте    │ │
│ └──────────┘                           └────────────┘ │
│                                                       │
│        [ нижняя панель: время / действия ]            │  ← ▶ ⏸ скорость, ползунок дней
└───────────────────────────────────────────────────────┘
```

- Отступ от краёв: 24 px (десктоп), 12 px (мобильный).
- Ширина боковых панелей: 320 px; панели **сворачиваются** в иконку.
- На мобильных: боковые панели становятся нижней выдвижной шторкой (bottom sheet), крошки сокращаются до «← Марс».
- Базовая единица отступов — 4 px (`4, 8, 12, 16, 24, 32, 48`).

## 5. Компоненты

Все компоненты — в `frontend/src/ui/`, на shadcn/ui + Tailwind, с вариантами для обоих настроений. Сделай страницу-витрину `/dev/ui` со всеми компонентами в обоих режимах.

- **Glass Panel** — фон `--bg-panel`, `backdrop-filter: blur(16px) saturate(140%)`, граница 1 px `--border-subtle`, радиус **8 px в космосе / 16 px в огороде**, мягкая тень. Основа всех панелей.
- **Object Card** (при наведении на звезду/планету) — название, тип, 3–4 ключевые цифры, мини-вердикт «🌱 Можно выращивать: под куполом» и кнопка «Лететь →». Появляется рядом с объектом, привязана к нему линией-выноской (тонкая линия 1 px, как в астрономических атласах).
- **Data Row** — `иконка · подпись · значение · единица · бейдж источника`. Бейдж — маленькая точка цвета `--data-real/estimate/hypo`, при наведении — подсказка с источником и датой.
- **Factor Bar** — горизонтальная полоска 0–100% с зонами ok/stress/lethal на фоне и маркером текущего значения. Используется для температуры, света, давления, гравитации, радиации.
- **Crop Card** — круглая иконка культуры (процедурный рендер растения), название, «оптимум: 15–20 °C», цветная полоска совместимости с текущей планетой.
- **Time Bar** (огород) — большая круглая кнопка ▶ (янтарная, 56 px), скорость `1× 5× 20×`, ползунок с маркерами событий (иконки ❄ 🌪 ☀ ☠), счётчик «Сол 47 / 120» моноширинным шрифтом.
- **Toast-события** — «❄ Ночной заморозок −92 °C — купол удержал +4 °C». Всплывают снизу справа, живут 4 с, накапливаются в журнал.
- **Breadcrumbs** — разделитель `›`, текущий уровень жирнее, остальные кликабельны.
- **Кнопки:** primary (заливка `--accent`, тёмный текст), secondary (стекло + граница), ghost (только текст/иконка). Высота 40 px, иконка + текст.
- **Иконки** — `lucide-react`, толщина линии 1.5, размер 16/20/24. Свои иконки культур — процедурные мини-рендеры, не эмодзи (эмодзи только в тостах).

## 6. 3D-визуал по уровням

### 6.1 Вселенная и галактика (реализм)
- Галактики — частицы с аддитивным смешиванием, тёплое ядро, голубоватые рукава, тёмные пылевые полосы (частицы с отрицательной яркостью/тёмным цветом поверх).
- Фон — едва заметные далёкие звёзды (2–3 слоя параллакса) + очень слабая туманность. **Не перебарщивать с цветом:** космос в основном чёрный.
- Звёзды с планетами — чуть крупнее и с мягким ореолом; при наведении — тонкое кольцо `--accent`.
- Bloom: умеренный (`intensity ≈ 0.8`, высокий порог), только для ярких объектов.

### 6.2 Звёздная система
- Орбиты — тонкие линии 1 px `--border-subtle`, выбранная — `--accent`.
- Обитаемая зона — полупрозрачное кольцо `--habitable` с прозрачностью 8–12% и мягкими краями.
- Планеты — реалистичные (текстуры NASA для Солнечной системы), но с лёгким ободком атмосферы (fresnel-шейдер) для читаемости на чёрном.
- Подписи планет — Space Grotesk 12 px, капслок, разрядка 0.12em, появляются при приближении.

### 6.3 Посадка (переход космос → огород) — 3–4 секунды
1. Камера летит к планете, планета заполняет экран.
2. Вход в атмосферу: экран заливает цвет неба планеты + облака/пыль частицами; без атмосферы — просто быстрое приближение к поверхности.
3. Плавный переход «настроения» UI: CSS-переменные анимируются 600 мс от `space` к `garden`, радиусы панелей округляются.
4. Камера опускается к огороду под углом ~35° (изометрия-«уют»).

Кнопка «Пропустить» появляется через 0.5 с. Учитывать `prefers-reduced-motion`: тогда — простое затемнение.

### 6.4 Огород (стилизация)
- **Стиль геометрии:** low-poly с мягкими нормалями, **toon/cel-освещение** (2–3 ступени света) + мягкий rim-свет по краю объектов. Тени мягкие.
- **Направление и цвет света — из данных** (позиция звезды, цвет по `st_teff`, яркость по освещённости), но стилизованы: яркость сжимается в приятный диапазон, а реальная цифра показывается в панели. *Правило: стилизуем картинку, никогда не стилизуем цифры.*
- **Пресеты окружения:**
  | Мир | Небо днём | Грунт | Атмосферные частицы |
  |---|---|---|---|
  | Земля | голубое | тёмная земля, трава | лёгкие пылинки, бабочки |
  | Марс | рыже-бежевое, закат голубоватый | ржаво-красный реголит, камни | пыль, пылевые вихри |
  | Луна | чёрное со звёздами, Земля на небе | серый реголит, кратеры | нет |
  | Титан | густой оранжевый туман | тёмный лёд, «песок» из органики | медленная морось |
  | Планета у красного карлика | тёмно-бордовое, огромная красная звезда | по типу | вспышки звезды — короткая засветка |
  | Ледяная/холодная экзопланета | бледно-синее | лёд, иней | снежинки |
- **Грядки** — деревянные/композитные короба со скруглёнными углами, тёплый `--soil` внутри, маленькие таблички с названием культуры.
- **Купол** — стеклянная полусфера: френель-шейдер, едва заметные шестиугольные рёбра, внутри свет теплее и слегка зеленоватый.
- **Подземная ферма** — уютное помещение: стеллажи, розово-фиолетовые LED-полосы, лёгкое свечение, мягкий гул вентиляции (если будет звук).
- Мелкие детали для жизни: маленький ровер-помощник рядом с огородом, лейка, ящики, следы на грунте. Без перегруза — максимум 5–7 декоративных объектов.

### 6.5 Растения
- Стилизованные, чуть «пухлые» пропорции, мягкие цвета, сочная зелень `--leaf` у здоровых.
- Стресс читается **силуэтом и цветом одновременно** (см. `INTERACTIVE.md` §4): поникание, вытянутость, пожелтение, синеватость, пятна.
- Анимация роста — плавная, с небольшим «пружинящим» доводом (spring) при появлении нового листа.
- **Разрез почвы** для корнеплодов: срез грядки сбоку, слои грунта, корни тонкими светлыми линиями, клубни — округлые, с мягкой подсветкой при росте.
- Крупный план: фон размывается (depth of field), растение медленно вращается, сбоку графики.

## 7. Графики

Recharts, единый стиль в `ui/charts/`:
- Линии 2 px, без точек (точка только при наведении), сглаживание `monotone`.
- Сетка горизонтальная, `--border-subtle`, без вертикальных линий.
- Зоны ok/stress/lethal — полупрозрачные полосы фона.
- Подписи осей — Inter 12 px `--text-secondary`, значения — JetBrains Mono.
- Подсказка (tooltip) — Glass Panel.
- Линия «сегодня» в огороде — вертикальная `--accent`, движется вместе со временем.

## 8. Движение и анимации

| Что | Длительность | Кривая |
|---|---|---|
| Наведение, нажатие | 120 мс | `ease-out` |
| Появление панелей | 220 мс | `cubic-bezier(0.2, 0.8, 0.2, 1)` + сдвиг 8 px |
| Смена настроения UI | 600 мс | `ease-in-out` |
| Перелёт камеры между объектами | 1.2–2.5 с (зависит от расстояния) | плавный старт и финиш |
| Посадка | 3–4 с | см. §6.3 |

- Ничего не мигает и не трясётся без причины. Свечение «дышит» только у объекта под курсором.
- Камера после перелёта медленно дрейфует (едва заметно), чтобы сцена была живой.
- `prefers-reduced-motion` → без перелётов (затемнение), без дрейфа, без пружин.

## 9. Экраны состояния

- **Загрузка** — тёмный экран, логотип, медленно вращающаяся точка-планета, строка «Рассчитываем орбиты…» / «Готовим грядки…».
- **Нет данных** — «Для этой планеты не известна атмосфера — выбери вариант:» + пресеты. Никаких пустых экранов.
- **Ошибка источника** — мягкая плашка «Каталог NASA недоступен, показываем кешированные данные от 12.10.2026».
- **Растение погибло** — не «Game Over», а спокойная карточка: причина, день, «Что помогло бы: купол (+45 °C), LED (+300 мкмоль/м²/с)» и кнопка «Попробовать снова с куполом».

## 10. Логотип и название

- Название: **AstroCrop**, Space Grotesk 600.
- Знак: простая форма — росток из двух листьев, вписанный в орбиту (кольцо). Монохромный SVG, работает в 16 px. Нарисовать самому в коде, `frontend/src/ui/Logo.tsx`.

## 11. Доступность

- Контраст текста ≥ 4.5:1 на стеклянных панелях (проверять на самом светлом фоне сцены — небе Марса, а не только на чёрном космосе; при необходимости усилить непрозрачность панели).
- Всё доступно с клавиатуры: Tab по объектам сцены (список видимых объектов дублируется в левой панели), Enter — лететь, Esc — уровень выше, Пробел — ▶/⏸ в огороде.
- Фокус — кольцо 2 px `--accent`.
- Размер кликабельных зон ≥ 40×40 px.

## 12. Как проверять дизайн (для Claude)

1. Реализуй токены и компоненты, страницу `/dev/ui`.
2. Затем экраны в порядке: Солнечная система → посадка → огород Марса → крупный план картофеля → галактика → вселенная.
3. После каждого экрана — **скриншоты Playwright** в `docs/screenshots/design/` в трёх размерах: 1440×900, 1024×768, 390×844 (мобильный). Огород снимай для Земли, Марса и Луны.
4. Сам открой скриншоты и пройдись по чек-листу:
   - [ ] центр сцены свободен, панели не перекрывают главный объект;
   - [ ] все цифры моноширинные, с единицами и бейджем источника;
   - [ ] цвета только из токенов; настроение (space/garden) верное для уровня;
   - [ ] текст читается на самом светлом участке фона;
   - [ ] статус передан не только цветом;
   - [ ] на мобильном ничего не обрезано;
   - [ ] три слова: спокойно, живо, честно — выполняются?
5. Исправь найденное, пересними, закоммить. Итог и скриншоты «до/после» — в `docs/PROGRESS.md`.
