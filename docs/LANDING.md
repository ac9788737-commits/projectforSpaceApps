# Вход на сайт (лендинг)

Сайт открывается лендингом — тёмная страница с мозаикой спутниковых полей, четырьмя полями для начала и картой для своего поля. Дизайн сделан отдельно и выгружен одним HTML-файлом («index (5).html»); он взят как есть.

## Как устроено
- `frontend/public/landing.html` — готовый лендинг. Его собирает `python frontend/scripts/build-landing.py "index (5).html"` из файла дизайнера: дизайн не меняется, подключаются только кнопки.
- Адрес `/` отдаёт лендинг: в Docker — nginx (`frontend/nginx.conf`, `location = /`), при разработке — Vite (`vite.config.ts`, плагин `astrocrop-landing`). Переход приложения на `/` или `/fields` возвращает на лендинг.

## Куда ведут кнопки
| На лендинге | Куда |
|---|---|
| «Собрать план» у поля | `/fields/<id>/plan` — конструктор «Что сеять?» |
| «паспорт поля» | `/fields/<id>` — паспорт поля |
| «Откуда цифры» | `/reference` |
| «Режим эксперта» | `/expert/fields` |
| «Нарисовать поле» → «Готово» → «Собрать план» | поле сохраняется (`POST /api/fields`) и открывается в конструкторе |
| RU / EN / TG | язык общий с приложением (`localStorage`: `astrocrop.lang`) |

Порядок полей в дизайне: Гиссар, Айова, Пенджаб, Кения (`tj-hissar`, `us-iowa`, `in-punjab`, `ke-nakuru`).

## Что нужно знать
- Лендинг берёт из интернета иконки Phosphor (unpkg.com), спутниковые снимки Esri и поиск адресов Nominatim; без сети страница откроется, но без иконок и снимков на карте.
- Это дизайн другого автора в другом стиле (тёмный, салатовый акцент, градиенты). Он лежит вне `src/`, поэтому `design-lint` его не проверяет.
- Если дизайнер пришлёт новую версию файла, достаточно снова запустить `build-landing.py`: скрипт сам скажет, если не найдёт нужную кнопку.
